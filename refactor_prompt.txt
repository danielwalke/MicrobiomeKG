# Graph Processing Pipeline Architecture

The system is structured as a sequential, six-stage data processing pipeline designed for graph manipulation. Each stage is isolated within its own dedicated directory under the `src/` folder. 

## Universal Stage Pattern
Every individual stage in the pipeline strictly adheres to the following internal execution pattern:
1. **Primary Operation:** The specific graph transformation or filtering task assigned to that stage.
2. **Metagraph:** Generation or updating of the graph's metadata representation.
3. **Clone:** Creating a cloned state of the processed graph.

The pipeline is entirely linear. The output of the `Clone` step from one stage serves directly as the input for the `Primary Operation` of the subsequent stage.
